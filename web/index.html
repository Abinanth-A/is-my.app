Two ways to use it

Point it. Or ship it.

Mode 01

Point

Your app already runs on GitHub Pages, Vercel, Netlify, Cloudflare Pages or your own box? Add a CNAME, A, AAAA, MX or TXT record and it resolves in under a minute.

"records": { "CNAME": "you.github.io" }
  • Bring any host
  • Email and verification records
  • Optional Cloudflare proxy
Mode 02

Deploy

No hosting at all? Give us your app's public GitHub repo, a build command and an output folder. We build it in an isolated container and serve it from Cloudflare's edge. Push to your branch and it redeploys.

"deploy": { "repo": "you/site", "build": "npm run build", "output": "dist" }
  • Any static framework
  • Automatic HTTPS
  • Auto redeploy on push

    Questions
    
        
    Good questions.
    
      
    
      
    
        
    Is it actually free?
    Yes. DNS runs on Cloudflare's free plan and builds run on GitHub Actions, which is free for public repositories. There is nothing to bill you for.
    
        
    How fast does it go live?
    Valid pull requests merge themselves. DNS is written within a minute of the merge. Hosted apps take as long as your build, usually one or two minutes.
    
        
    My app is on Vercel, Netlify or GitHub Pages. Anything special?
    Add your-app-name.is-my.app as a custom domain on your host first, then point a CNAME at the target it gives you. The recipes have the exact file for each host.
    
        
    What can the deploy mode build?
    Any app that produces static files: Vite, React, Svelte, Astro, Next static export, Hugo, Jekyll, plain HTML. Builds run in a node container with no secrets, get 15 minutes, up to 20,000 files and 25 MiB per file. We check your branch every hour and redeploy when it moves.
    
        
    Do I get HTTPS?
    Always. In deploy mode Cloudflare issues the certificate for you. In point mode your host issues it, just like any custom domain.
    
        
    How many apps can I have?
    Up to five apps per GitHub account, plus nested names under them, with up to 50 DNS records in total. Your account needs to be at least two weeks old.
    
        
    Can I use a nested name like api.my-app?
    Yes, for DNS records, as long as you own my-app. Hosted apps and the Cloudflare proxy need a top-level name, because Cloudflare's free certificate covers one level of subdomain.
    
        
    What is not allowed?
    Phishing, malware, spam, impersonation, anything illegal. Names that break the rules are removed without notice. Read the terms.
