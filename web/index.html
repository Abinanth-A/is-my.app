Two ways to use it

Point it. Or ship it.

Mode 01

Point

Already hosting on GitHub Pages, Vercel, Netlify, Cloudflare Pages or your own box? Add a CNAME, A, AAAA, MX or TXT record and it resolves in under a minute.

"records": { "CNAME": "you.github.io" }
  • Bring any host
  • Email and verification records
  • Optional Cloudflare proxy
Mode 02

Deploy

No hosting at all? Give us a public GitHub repo, a build command and an output folder. We build it in an isolated runner and serve it from Cloudflare's edge. Push to your branch and it redeploys.

"deploy": { "repo": "you/site", "build": "npm run build", "output": "dist" }
  • Any static framework
  • Automatic HTTPS
  • Auto redeploy on push

    Questions

    Good questions.

    Is it actually free?

    Yes. DNS runs on Cloudflare's free plan and builds run on GitHub Actions, which is free for public repositories. There is nothing to bill you for.

    How fast does it go live?

    DNS records are written within a minute of your pull request being merged. Hosted repos take as long as your build, usually one or two minutes.

    I host on Vercel, Netlify or GitHub Pages. Anything special?

    Add yourname.is-my.app as a custom domain on your host first, then point a CNAME at the target it gives you. For GitHub Pages verification, add a TXT record at _github-pages-challenge-you.yourname.

    What can the deploy mode build?

    Anything that produces static files: Vite, Astro, Next static export, Hugo, Jekyll, plain HTML. Builds get 15 minutes, up to 20,000 files and 25 MiB per file. We check your branch every hour and redeploy when it moves.

    Do I get HTTPS?

    Always. In deploy mode Cloudflare issues the certificate for you. In point mode your host issues it, just like any custom domain.

    How many can I claim?

    Up to five top-level names per GitHub account, plus any nested records under them. Your account needs to be at least two weeks old.

    What is not allowed?

    Phishing, malware, spam, impersonation, anything illegal. Names that break the rules are removed without notice. Read the terms.
